# CP-017: baseball fieldwork and modular source intake

Research preceded curriculum selection. Author-written baseball examples were evaluated for spreadsheet-sized procedures, choosing arsenal proportions, within-type velocity, location/whiff denominators and contact comparisons while deferring predictive models and MDS. Both supplied ZIP archives were inspected without running their scripts, workspaces or HTML. Hashes and a code-recovery map are in the archive audit. The R track adapts the owner-supplied pitcher subset/px-pz/pitch-type comparison with full samples, consistent scales and repaired wiring.

The initial planted-practice implementation followed the fixture request. User feedback clarified that real observations should anchor the course. The final design therefore has a three-lesson primary real-data course and a separate five-lesson known-answer practice lab; source data and synthetic rows are never mixed.

## Source-intake checkpoints

Tests were written and observed failing for the missing baseball modules/course and unsupported source adapter. Subsequent tests exposed missing HTTP-304 handling and an existing-response validator gap; both were fixed and their regressions pass. The reusable engine now supports registered CSV schema/checksum contracts, Mendeley file-list metadata checks, bounded downloads and redirects, content-addressed storage, source-version/DOI/license provenance, append-only revisions/attempts, and conditional direct GET refresh.

The retained real source is Nathan David Pifer's CC BY 4.0 college tracking dataset, Mendeley Data V3, doi:10.17632/xfnz6mkdzm.3. Its 2,209,410-byte CSV matches published SHA-256 7b7b8974107be6181dcf1880d609034ef9f7556f9fb13aec021a52d37cd0c190 and is unchanged. An actual second refresh logged unchanged and avoided a CSV reload. Initial attempts exposed the repository's public storage redirect host; that exact host was checked and allowlisted before successful intake. Failures remain in the attempt log.

The full file contains 3,344 measured pitches and 141 columns. The analysis reports 1,745 operator-tagged Fastball pitches, 381 misses among 1,432 swings and 549 InPlay records, preserving anonymous IDs, altered date labels and structural missingness. Twenty distinct date labels are not silently treated as the paper's 21 games. Coordinate signs and source units stay explicit.

## Dataset and course checkpoints

The separate deterministic fixture has 3,600 pitches, six fictional pitchers and twelve hitters. Tests verify the planted 60%-to-40% FF-share change, a within-FF inning-speed decline, appropriate outcome relationships, contact-period change, controls, valid filters, undefined zero-denominator rates, all chart families, and byte reproduction. It remains visibly synthetic.

Both courses use shared lesson sections, glossary, quizzes and progress. Baseball adds explicit Excel/spreadsheet tracks, separate real/practice notebooks and R/Power BI guides, filtered reference plots and summaries, and clear dataset-specific notices/downloads. A percentage quiz recognizes the fraction-versus-percent error. The browser regression suite caught a duplicate top-level test variable; its evaluation was scoped and the complete suite passed afterward.

Both base-R scripts executed locally using installed R 4.3.1, verified their numerical checks and wrote PDF/CSV outputs. R emitted host locale-startup warnings, but neither script failed. Linux CI now executes both sports scripts. Interactive spreadsheet/Power BI and visual judgement remain manual, as does physical print fit for the unrelated game.
