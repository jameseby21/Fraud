# CP-012: linked term index and section checks

The acceptance tests were written first and failed because the glossary loaders, quiz evaluator, API routes, documentation, and UI did not exist. The first green pass covers 33 reviewed terms, all five standard sections in each of eleven lessons, answer privacy in lesson responses, and specific recognition of unfiltered mean, cents-versus-dollars, and median-versus-mean mistakes.

The course now marks glossary aliases with a visible dotted underline. A keyboard-operable button opens a native dialog containing a definition, more context, and analytical implications. The searchable Term index uses the same JSON source as [the documentation glossary](../glossary.md). Rendering uses DOM text nodes and `textContent`; code, links, form controls, and quiz cards are excluded from annotation.

Every Question, Try it, Check your work, Debugging, and Reflection section gets one inline check. The browser sends an answer only to the local Python server, receives correct/incorrect feedback, and stores nothing. `data/learning/common_errors.json` is the appendable suggestion repository. Unknown answers receive a section-specific review prompt rather than an invented diagnosis.

Wiring quizzes exposed an existing flow defect: after the Check your work heading, Debugging and Reflection were also placed inside the spoiler panel. Section-aware rendering now keeps only the worked check collapsed and restores the remaining lesson flow.

Focused validation passed 23 learning/HTTP tests and course-generation verification. The expanded headless Edge suite passed term annotation, dialog content, all five section checks, correct-answer feedback, filtered-average guidance, term-index search, existing track/progress behavior, and mobile overflow. Full verification passed 125 tests with zero skips plus publication, source-byte, documentation, fixture, record-library, generated-course, generated-case, and JavaScript checks. The first restricted run could not enforce Windows ACLs in temporary vault-test folders; the required unrestricted rerun passed every vault test. A live-server smoke check returned `/learn` 200, 33 terms, five quizzes for the selected lesson, and the expected filter suggestion. Remote delivery is recorded after the checkpoint commit. Power BI Desktop remains manual.
