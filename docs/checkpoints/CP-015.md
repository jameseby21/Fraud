# CP-015: printable case-file game

Acceptance tests were written first and failed because the game fixture module, routes, downloads, UI, and assets did not exist. Version 1.0.0 adds four entirely fictional cases: same-day round totals, suspicious number construction, polished confirmations versus a complete market tape, and missing authorization references concentrated in one branch.

Each player packet has 16 ledger rows, an inbox, three reference cautions, and four scoped candidate groups. Answers remain in a separate facilitator artifact and are absent from the catalog and player-case API. The paper version needs no code: print a Markdown case page and its CSV ledger, distribute a score sheet, and retain the facilitator key. The browser version adds cooperative or competitive mode, team name, timer, submission, feedback, print styling, and a local-only score list that users can clear.

Scoring gives case-specific points for supported targets, 20 for complete target coverage, up to 20 for speed, and subtracts 15 for each unsupported choice. A perfect round-total submission earns 100 points. Scores are deterministic game mechanics and do not represent real damages, criminality, severity, fraud probability, or model accuracy. Every rationale asks for corroborating evidence and preserves group-level inference limits.

The analyst extensions link three cases to the matching forensic-practicum lessons and the authorization case to the sourced Wells Fargo guide while keeping the game ledger wholly invented. The generator writes 17 reproducible artifacts: public catalog, four player JSON files, four ledgers, four print pages, rules, score sheet, facilitator answers, and manifest.

Focused validation passed 21 game and HTTP tests plus generator and JavaScript verification. Headless Edge passed four-case loading, pre-submit answer separation, 16-row rendering, perfect scoring, browser-local results, the advanced case, existing library/course flows, and mobile width. Full verification passed 144 tests with zero skips, 84 staged-data byte checks, 95 linked documents, all four fixture generators, 17 game artifacts, 13 lessons/notebooks, 26 resolved-case guides, publication scanning, and JavaScript syntax checks. Print-to-paper fit was implemented with Letter portrait CSS and compact tables; physical-printer acceptance remains a manual playtest.
