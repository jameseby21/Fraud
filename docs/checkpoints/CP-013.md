# CP-013: market-context statement exercises

Acceptance tests were written first and failed because the market fixture, retained CFTC source, two lessons, download routes, and revised Madoff source did not exist. The implementation adds two deliberately subtle exercises: internally perfect synthetic confirmations that exceed a complete synthetic market tape by 0.853%, and fictional final positions that exceed an exact retained CFTC open-interest aggregate by 0.860%. Both answer keys state the correct inference limit: the scoped group cannot all be true, but the aggregate does not identify a false row, actor, or intent.

Version 1.0.0 contains 240 fictional accounts, 8,000 confirmations, 2,000 market-context rows, 4,000 positions, and 15 exact public reference rows. Forty planted confirmation lines are hidden among 7,960 controls; each line remains below 4% of the matching daily volume. Fourteen of fifteen position groups remain below their public capacity. Source ID, retained-byte SHA-256, report date, publication date, units, transformations, and real-versus-synthetic boundaries travel with the artifacts.

The two new five-section lessons work in Markdown, clean Python notebooks, the shared R script, and the Power BI guide. The UI chooses the correct primary table and instructor key, offers all supporting downloads, annotates the new open-interest term, and retains one local quiz in every lesson section. A browser regression test initially expected the older forensic answer key; the failure confirmed the intended new behavior and the assertion was corrected to require the market-specific key.

The former FBI Madoff catalog URL, which returned 403 to the user, now points to the DOJ case page. The source library preserves its earlier retained FBI response and records the blocked DOJ machine-download attempt instead of bypassing the site. The exercise documentation separately cites the SEC release about fictitious Madoff trades and does not present it as evidence for any fabricated fixture row.

Focused validation passed 39 market-fixture, record-library, HTTP, and learning tests. Headless Edge passed both lesson paths, glossary, quizzes, targeted suggestions, downloads, R and Power BI selections, progress, chart, mobile, catalog, and record checks. Full verification passed 134 tests with zero skips plus the publication scan, 80 staged-data byte checks, intake, 79-document graph, 28-revision record library, all three fixture generators, 13 lessons/notebooks, 20 case guides, and JavaScript syntax. Live app service remains available at `/learn`. Power BI Desktop and interactive local R acceptance remain manual.
